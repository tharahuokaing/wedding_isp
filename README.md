## 📌 Project Overview

This repository hosts the official frontend interactive web interface for the **ISP Technology Showcase & Ceremony** created by **Huokaing Thara & Khen Lida**. 

The platform blends modern web features—such as real-time character-by-character LED terminal animations, dual-language switching (Khmer & English), and audio stream triggers—with cultural elements and technical discussions regarding 6G vision, binary computing (`1s and 0s`), mnemonic seed phrase handover, and symbolic discussions.

---

## ✨ Key Features

* 🌐 **Bilingual Support (Khmer & English):** Seamlessly structured text blocks allowing users to read content in both languages side-by-side or stacked.
* ⌨️ **LED Running / Typewriter Animation:** Real-time character-by-character rendering for event sequences (`Script2.js`) with an animated LED cursor.
* 📜 **Smooth Auto-Scrolling:** Automated, scroll-to-view feature for real-time text execution logs.
* 🎵 **Interactive Audio Player:** One-click interview playback control.
* 📱 **Fully Responsive Layout:** Optimized for desktop monitors, tablets, and mobile displays.
